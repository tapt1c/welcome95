# Welcome95 1.0

Экран приветствия в стиле Windows XP для Windows 95 с выбором существующих
пользователей и настоящим полем пароля Windows. Русский и английский интерфейсы.

- Фиксированные размеры элементов при смене разрешения и отдельная компоновка
  для 640×480. Статусы запуска, входа и завершения работы.
- Однократная попытка входа без пароля для единственного аккаунта при загрузке;
  после выхода из системы всегда показывается выбор аккаунта.
- Выключение, перезагрузка и ждущий режим из экрана входа с затемнением.
- Буферизация GDI-кнопок, ранний фон до подготовки шрифтов и фон между сеансами.
- Управляемая установка в `%WINDIR%\LOGON`, резервные копии и журналы;
  доступ к настройкам через элемент Панели управления.
- В 1.0 оболочка из сохранённого `SYSTEM.INI` запускается за приветствием после
  подтверждённого входа. При появлении её окна приветствие убирается без анимации.
  Для оболочки без окна ожидание ограничено; обычный автозапуск ждёт закрытия экрана.
- Предоставленная автором иконка встроена в EXE и посредник Панели управления;
  свойства EXE содержат версию 1.0.0.0.

## Установка и обновление

Скачайте `WELCOME95.EXE` и запустите без параметров. Настройки откроются из
установленной копии в `%WINDIR%\LOGON`. Нажмите «Включить» и перезагрузите Windows.
Загрузчик, шрифты и посредник Панели управления уже встроены в один EXE.

При обновлении сначала откройте старые настройки, нажмите «Отключить» и закройте
их и предпросмотры. Затем запустите новый EXE, нажмите «Включить» и перезагрузите
Windows. Это устанавливает новый загрузчик, сохраняет прежнюю оболочку и обновляет
значок Панели управления. Резервные копии в LOGON сохраняются.

Программа не читает PWL или пароли и не создаёт пользователей. Проверка пароля
остаётся у Windows. Подробности и восстановление: [README](../README.md),
[BOOT_FLOW](BOOT_FLOW.md).

## Проверки

Сборка x86/i386 с подсистемой Windows 4.0, без CRT/.NET/TLS. Проверены импорты
основного EXE и встроенных загрузчика/CPL, версия EXE и пиксели иконки.
528 оконных проверок прошли в каждом режиме Wine64/Xvfb: 640×480×16,
800×600×24 и 1024×768×24, с приватными данными и инертной оболочкой. Настоящая загрузка, сетевой провайдер и порядок автозапуска
Windows 95 требуют проверки в целевой VM; Wine её не заменяет.
