# Welcome95 в Панели управления Windows 95

После успешного Enable устанавливается небольшой CPL-посредник. Он содержит
только название, описание, значок Windows из предоставленных ресурсов и команду запуска
WELCOME95.EXE из соседней папки. Все настройки и их интерфейс остаются в EXE.

Посредник встроен в основной EXE как RCDATA 301 и извлекается в новый файл
%WINDIR%\LOGON\W95xxxx.CPL. Копировать второй файл вручную не требуется.
Запуск происходит только после двойного щелчка, через CreateProcessA с полным
путём в кавычках. CPL_INIT/GETCOUNT/INQUIRE/NEWINQUIRE не запускают программу,
не изменяют автозапуск и не обращаются к паролю.

Регистрация сохраняет машинное значение Welcome95 в:

    HKLM\Software\Microsoft\Windows\CurrentVersion\Control Panel\Cpls

Для старого механизма обнаружения добавляется также единственный ключ
`Welcome95` в `[MMCPL]` файла `%WINDIR%\CONTROL.INI`, указывающий на тот же CPL
в LOGON. Файл посредника не копируется в SYSTEM. В обеих регистрациях проверяется
принадлежность и сохраняется прежнее значение для отката. Остальные элементы и
разделы CONTROL.INI не меняются. Установка прежней версии только с записью Cpls
может получить запись MMCPL при повторном Enable.

Наличие ключа определяется перечислением имён `[MMCPL]`, без служебного символа
в значении по умолчанию. Отсутствующие файл/раздел/ключ разрешают первую установку;
существующий пустой `Welcome95=` остаётся отдельной записью и защищён от чужой
перезаписи. Усечённый список ключей даёт ошибку до изменения файлов и автозапуска.

CPL_INQUIRE возвращает обычные идентификаторы встроенного значка и STRINGTABLE
с названием и описанием на русском/английском. Старому хосту не требуется
CPL_NEWINQUIRE для получения метаданных; динамический ответ сохранён для других
хостов. PE-аудит проверяет ресурсы непосредственно в x86 CPL.

Единственная REG_BINARY-запись Entry в HKLM\Software\Welcome95\ControlPanel
хранит версию, владельца EXE, путь посредника, размер и контрольную сумму.
Перед изменением проверяются владелец, принадлежность каталогу LOGON, форма
имени и исходное содержимое. Чужая регистрация и изменённый зарегистрированный
файл не перезаписываются. Соседние значения Cpls не меняются.

Регистрация значка предшествует настройке загрузки, но сохраняется только при
успешном Enable. Ошибка первой установки возвращает прежние значения и удаляет
новый собственный файл, если он свободен. При неудачном повторном применении
возвращается прежний значок вместе с обеими регистрациями. Реальная ошибка отката
остаётся видимой. WritePrivateProfileString(NULL, NULL, NULL, ...) может вернуть
ноль при успешном сбросе кэша: проверяется GetLastError и итоговая запись, а не
только BOOL. Отказ записи, явная ошибка сброса и несовпадение readback отменяют
применение до изменения автозапуска.

Disable отключает экран и восстанавливает оболочку, сохраняя доступ к настройкам
через Панель управления. Повреждение или чужое изменение регистрации значка
не блокирует отключение экрана. Отдельная функция удаления собственной
регистрации проверена для случая загруженного CPL; она не является новой
пользовательской кнопкой удаления программы.

Обновление посредника создаёт новый собственный файл вместо замены загруженного.
Предыдущий модуль после переключения регистрации возвращает GETCOUNT=0; новый
возвращает 1. Старые файлы остаются в LOGON для открытых окон и отката. Имя
резервируется через CREATE_NEW и имеет строго четыре шестнадцатеричные цифры:
GetTempFileName при явном unique может выдавать меньше цифр.

CPlApplet экспортируется без декорации stdcall. Production CPL — i386, Windows 4.0,
без CRT/TLS/.NET, только 15 проверенных импортов KERNEL32/USER32/ADVAPI32.
Настоящая загрузка и вызовы ABI проверяются отдельной 64-битной сборкой под Wine;
хранилище — частные HKCU/INI/файлы, запуск EXE заменён инертным callback.
Тестовый экспорт настройки хоста отсутствует в production и запрещён PE-аудитом.
Отображение/обновление списка в родной Панели управления Win95 требует проверки
в VM. При уже открытой Панели может потребоваться обновление или повторное открытие.

Упрощённая Панель Explorer95 имеет фиксированный список элементов. Для системного
списка используйте «Все параметры» / «View all Control Panel options». Это
проверено по исходному коду Explorer95, коммит
[cb970dac](https://github.com/tapt1c/explorer95/blob/cb970dac91a1c31ac8433df27a1063a9967f8d1a/src/browser_control_panel.c).
Welcome95 не изменяет другой репозиторий или встроенный список Explorer95.
